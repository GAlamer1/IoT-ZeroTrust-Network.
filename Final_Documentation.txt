====================================================
Final Documentation
Project: IoT Zero Trust Isolated Network
====================================================

1) Overview
-----------
A network split into 5 isolated VLANs, where every device can
only reach what it actually needs (Default Deny), enforced
through ACLs on the router and Port Security on the switch.

2) Devices (13 total)
----------------------
Router0, Switch0, Server0,
Camera1, Camera2, Sensor1, Sensor2,
Admin-PC, User-PC1, User-PC2

3) VLAN and IP Addressing Table
---------------------------------
VLAN 10 Cameras  192.168.10.0/24  Gateway 192.168.10.1
VLAN 20 Sensors  192.168.20.0/24  Gateway 192.168.20.1
VLAN 30 Admin    192.168.30.0/24  Gateway 192.168.30.1
VLAN 40 Users    192.168.40.0/24  Gateway 192.168.40.1
VLAN 99 Servers  192.168.99.0/24  Gateway 192.168.99.1
Server0 = 192.168.99.10 (Static)

4) Switch Ports
------------------
Fa0/1 -> Router0   (Trunk)
Fa0/2 -> Server0   VLAN 99
Fa0/3 -> Camera1   VLAN 10
Fa0/4 -> Camera2   VLAN 10
Fa0/5 -> Sensor1   VLAN 20
Fa0/6 -> Sensor2   VLAN 20
Fa0/7 -> Admin-PC  VLAN 30
Fa0/8 -> User-PC1  VLAN 40
Fa0/9 -> User-PC2  VLAN 40

5) Access Matrix (Zero Trust)
--------------------------------
Cameras  -> Server only
Sensors  -> Server only
Admin    -> Cameras + Sensors + Server (denied from Users)
Users    -> Server + internet only (denied from all local VLANs)

6) Security Layers Implemented
----------------------------------
- Micro-segmentation via VLANs
- ACLs with Default Deny principle on the router (110, 120, 130, 140)
- Port Security on every device port (Maximum 1, Sticky, Violation: Shutdown)
- Centralized DHCP via Server0 + DHCP Relay (ip helper-address)

7) Test Results (Ping)
---------------------------
Camera1  -> Server0    : Success
Camera1  -> Admin-PC   : Failed (as expected)
Camera1  -> User-PC1   : Failed (as expected)
Admin-PC -> Camera1    : Success
Admin-PC -> User-PC1   : Failed (as expected)
User-PC1 -> Server0    : Success
User-PC1 -> Camera1    : Failed (as expected)

8) Methodology Note
-----------------------
Packet Tracer does not support every real Zero Trust concept
(such as per-session continuous verification). The principle
was simulated through segmentation, ACLs, port authentication,
and centralized DHCP, within the simulator's capabilities.
