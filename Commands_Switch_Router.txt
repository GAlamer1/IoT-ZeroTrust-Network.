====================================================
IoT Zero Trust Isolated Network Project
Switch and Router CLI Commands
====================================================

Note before starting:
If any device asks:
  "Would you like to enter the initial configuration dialog?"
  Type: no  then press Enter

====================================================
PART 1: Switch Commands (Switch0)
====================================================

--- Step 1: Enter configuration mode ---

enable
configure terminal


--- Step 2: Create the five VLANs ---

vlan 10
name Cameras
exit

vlan 20
name Sensors
exit

vlan 30
name Admin
exit

vlan 40
name Users
exit

vlan 99
name Servers
exit


--- Step 3: Trunk port (connects to the router) ---

interface FastEthernet0/1
switchport mode trunk
exit


--- Step 4: Device access ports ---

interface FastEthernet0/2
switchport mode access
switchport access vlan 99
exit

interface FastEthernet0/3
switchport mode access
switchport access vlan 10
exit

interface FastEthernet0/4
switchport mode access
switchport access vlan 10
exit

interface FastEthernet0/5
switchport mode access
switchport access vlan 20
exit

interface FastEthernet0/6
switchport mode access
switchport access vlan 20
exit

interface FastEthernet0/7
switchport mode access
switchport access vlan 30
exit

interface FastEthernet0/8
switchport mode access
switchport access vlan 40
exit

interface FastEthernet0/9
switchport mode access
switchport access vlan 40
exit


--- Step 5: Save ---

end
write memory


====================================================
PART 2: Router Commands (Router0)
====================================================

--- Step 1: Enter configuration mode ---

enable
configure terminal


--- Step 2: Enable the main physical interface ---

interface GigabitEthernet0/0
no shutdown
exit


--- Step 3: Create Sub-interfaces for each VLAN ---
(each one needs its own "no shutdown")

interface GigabitEthernet0/0.10
encapsulation dot1Q 10
ip address 192.168.10.1 255.255.255.0
ip helper-address 192.168.99.10
no shutdown
exit

interface GigabitEthernet0/0.20
encapsulation dot1Q 20
ip address 192.168.20.1 255.255.255.0
ip helper-address 192.168.99.10
no shutdown
exit

interface GigabitEthernet0/0.30
encapsulation dot1Q 30
ip address 192.168.30.1 255.255.255.0
ip helper-address 192.168.99.10
no shutdown
exit

interface GigabitEthernet0/0.40
encapsulation dot1Q 40
ip address 192.168.40.1 255.255.255.0
ip helper-address 192.168.99.10
no shutdown
exit

interface GigabitEthernet0/0.99
encapsulation dot1Q 99
ip address 192.168.99.1 255.255.255.0
no shutdown
exit


--- Step 4: Save ---

end
write memory


====================================================
Verification
====================================================

show ip interface brief

Expected: every interface (Gi0/0 and all sub-interfaces) shows "up / up"

====================================================
Quick reference - Switch ports
====================================================

Fa0/1  -> Router0        (Trunk - all VLANs)
Fa0/2  -> Server0         VLAN 99
Fa0/3  -> Camera1         VLAN 10
Fa0/4  -> Camera2         VLAN 10
Fa0/5  -> Sensor1         VLAN 20
Fa0/6  -> Sensor2         VLAN 20
Fa0/7  -> Admin-PC        VLAN 30
Fa0/8  -> User-PC1        VLAN 40
Fa0/9  -> User-PC2        VLAN 40

====================================================
Quick reference - IP Addressing
====================================================

VLAN 10 (Cameras)  -> 192.168.10.0/24   Gateway: 192.168.10.1
VLAN 20 (Sensors)  -> 192.168.20.0/24   Gateway: 192.168.20.1
VLAN 30 (Admin)    -> 192.168.30.0/24   Gateway: 192.168.30.1
VLAN 40 (Users)    -> 192.168.40.0/24   Gateway: 192.168.40.1
VLAN 99 (Servers)  -> 192.168.99.0/24   Gateway: 192.168.99.1
                       Server0 = 192.168.99.10 (Static)
